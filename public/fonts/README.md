# Local font assets

Google Fonts: Noto Serif SC, Noto Serif TC and Abril Fatface, original WOFF2 subsets and CSS. The corresponding OFL licenses are included.

DYmingA: original subsets and CSS from https://fontsapi.zeoseven.com/35/main/result.css. Original copyright and IPA license notices are retained in dyming/fonts.css.

Font files are copied without modification. Family names, weights, unicode ranges and font-display are preserved. Browsers download only subsets needed for visible characters.
